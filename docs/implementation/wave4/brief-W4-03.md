## Work
1. **Ability catalog: `Abilities/LHAbilityCatalog.h/.cpp`.** Native `ULHAbilityDefinition`-like rows (Id, Eligibility, LearningSkillPoints, LearningGold, ManaCost, RangeCm, CooldownSeconds, ImpactSeconds, Effects, Policies, classification tag); `LHAbilities::Catalog()`, `Find(const FLHContentId&)`. Rows: `Attack.Melee.Basic`, `Attack.Ranged.Bow`, `Spell.Light`, `Spell.FireDart`, `Spell.HealLight`, `Spell.StoneShard`, `Spell.DustDevil`. Values from the lookup/ledgers (Bible spell table: learning level/WIS/INT/points/gold, MP; recorded status). Only where the lookup says `missing`: **Prototype** + provenance (ledger proposals: cast interval 1500 ms; magnitude uniform in the measured classic range at minimum requirements). If Light/Heal Light stay `missing`: Heal Light = instant heal, Prototype magnitude; Light = castable non-damage, non-saved transient effect (D12 effect allowlist stays empty).
2. **Equipment combat types: `Abilities/LHEquipmentCombat.h`.** `FLHWeaponCombatData` (min/max damage, bow flag, compatible quivers, quiver damage bonus, `QuiverConsumption=Unlimited` policy), `FLHConsumableEffect` (e.g. mana restore). W4-02 fills them; test with fixtures (Rusted Dirk 1–4, Ashwood Flatbow 1–3, Wooden Arrows +1 unlimited, Potion of Mana +25 MP; ledger).
3. **Config builder.** `LHAbilities::BuildAttackConfig(const FLHSaveSnapshot&, const FLHContentId& Ability, <item lookup>, <combat parameters>, FLHBasicAttackConfig&, FString&)`: range/damage from the equipped weapon; `Attack.Ranged.Bow` needs bow + equipped compatible quiver (`BowRequiresQuiver`); never decrement Wooden Arrows; learned Attack/Archery/Dodge skills are rules inputs. Physical coefficients: caller-supplied `LH::Rules::FCombatParameters` (reject unresolved). Also `LH::Rules::MakeStage1PrototypeCombat()` in `Rules/` from the lookup, else the ledger's "Physical resolution" Prototype row (hit chance clamp(Attack/(Attack+Dodge), 0.10, 0.95), Archery for bows, damage = weapon roll + floor(STR/5) − AC, min 1); if linear `FCombatParameters` can't express the ratio, add a typed variant (don't approximate; say so). W4-06's profile uses it.
4. **UseAbility authority.** `ELHCommandReason LHAbilities::ExecuteUseAbility(FLHUseAbilityContext&, const FLHUseAbilityRequest&)`; context = source/target `ULHCombatComponent`s, snapshot copy, lookups. Validate knowledge (learned spell or base attack), equipment, life state, mana, per-ability cooldown, range/LOS, target policy; commit via the existing component. Precommit rejection is free; after commit, `NoRefundAfterCommit` (D09). Extend `ULHCombatComponent`: multiple abilities, **per-ability cooldowns**, spell impacts (damage vs heal); keep serial/identity discipline (D16). Keep `ConfigureAttack`, `RequestBasicAttack`, `ValidateAttack`, `OnDeath` source-compatible (W4-01 uses them). No receipts (W4-06's session wrapper).
5. **Item use (UseItem, Matt Q5; command from W4-08).** `ELHCommandReason LHAbilities::ExecuteUseItem(FLHUseItemContext&, const FLHUseItemRequest&)` in `Abilities/LHItemUse.*`; context: snapshot copy (W4-06 syncs GAS first), item lookup, life state. Owned item with a `FLHConsumableEffect`, else `NotUsable`; Potion of Mana: full mana rejects `NoEffect` unconsumed; clamp; consume exactly one; atomic. Reason codes: Core (`schema-rev2.md`); add none. No receipts (W4-06 wraps it as a persisted command, then pushes mana to GAS). No `Consumable.*` ability IDs.
6. **D14 delegates** on `ULHCombatComponent`: `OnAttackCommitted`, `OnAttackCancelled` (reason Explicit/SourceDeath/AvatarCleared/Travel), `OnAttackFinished` (ResolvedHit/ResolvedMiss/ImpactInvalidated/Cancelled); value-captured identity; re-entrancy safe.
7. **Mana regen and cooldown persistence.** `LHAbilities::AdvanceManaRegen(FLHSaveSnapshot&, double AliveUnpausedSeconds, const LH::Rules::FManaParameters&)` via `Rules::RegenerateMana` + `ManaRegenFractionalSeconds`; a runtime ticker for live GAS Mana (same rule; alive, unpaused; W4-06 exports its carry at boundaries); `CaptureCooldowns(const ULHCombatComponent&, const FLHEntityId& Owner, TArray<FLHCooldownRecord>&)` / `RestoreCooldowns(...)`. Pause/death/menus/load add no ticks; floor travel never resets cooldowns.
8. Pure formulas (spell magnitude, ranged damage) go in `Rules/` with tests; no second rules engine.
9. Doc `docs/implementation/abilities.md`: catalog table + provenance, policies, interfaces above, open items (all that the lookup leaves `missing`, e.g. cancellation/refund).

## Acceptance (`Lighthaven.Abilities.*`, `Lighthaven.Rules.*`)
- `Lighthaven.Abilities.MeleeRangeAndLOS`: legal melee hit; out-of-range/through-wall reject at no cost.
- `Lighthaven.Abilities.BowRequiresQuiver`: bow without quiver rejects (Ineligible); with Wooden Arrows succeeds; quiver quantity unchanged after N shots.
- `Lighthaven.Abilities.SpellKnowledgeAndMana`: unlearned spell rejects; insufficient mana rejects unmutated; learned Fire Dart deals damage within range; Heal Light clamps.
- `Lighthaven.Abilities.CancellationNoRefund`: cancel after commit keeps cost/cooldown; before commit charges nothing; D14 events fire once each.
- `Lighthaven.Abilities.ZeroManaNoGoldRecovery`: 0 MP, 0 gold → natural regen reaches cast cost; legal cast succeeds without reload.
- `Lighthaven.Abilities.RegenTimerReload`: fractional carry survives `LHSave::Encode/Decode`; pause/menu/load add no tick.
- `Lighthaven.Abilities.CooldownPersistence`: per-ability cooldowns survive save/reload/floor travel; no reset, no wall-clock catch-up.
- `Lighthaven.Abilities.ManaPotionEdges` (via `ExecuteUseItem`): full-mana use rejects `NoEffect` unconsumed; non-usable item rejects `NotUsable`; partial restore clamps; one potion consumed per accepted use.
- Existing Abilities/Rules/Integration tests pass.
